# Pace for Chrome: Privacy Policy

_Last updated: 23 October 2026_

Pace is a reading-focus overlay. It dims the page and keeps a clear band where you are reading. This policy covers the Pace Chrome extension.

## The short version

- Pace **never reads, stores or sends the text, images or other content of the pages you visit.**
- Pace **never collects your browsing history, URLs, page titles, keystrokes or form data.**
- The only thing the overlay uses is your **mouse's vertical position**, so the band can follow it. That position stays in the tab and is never stored or sent anywhere.
- Your settings (on/off, size, color, opacity, blur) are saved in Chrome's local extension storage on your device.
- Pace sends a small number of **anonymous usage events** (described below) so we can tell how many people use it and which features they use.

## Why Chrome says Pace can "read and change" your data on websites

Chrome shows this warning for any extension that can draw on web pages. Pace needs it for one reason: to place its dimming overlay on top of every page you open, including tabs that were already open when you turned Pace on. Pace adds its own overlay element to the page. It does not read or change the page's content.

## Anonymous usage events

When analytics is enabled in a release, Pace sends these events to PostHog (posthog.com), our analytics provider:

| Event | Extra data |
|---|---|
| `app_opened` | whether this is a new install |
| `popup_opened` | none |
| `pace_view_shown` / `pace_view_hidden` | how long the overlay was on, in seconds |
| `mode_activated` / `mode_deactivated` | band size (S/M/L) and how long it was used, in seconds |

Every event also carries: a random install ID generated by Pace (not tied to your name, email, Google account or device), the extension version, and the labels `platform: chrome_extension` and `browser: chrome`.

URLs, page titles, page content, IP-derived location beyond what PostHog records by default, and any personal information are **never** included. The code that builds these events strips URL and title fields even if they were added by mistake.

We use this data only to understand and improve Pace. We do not sell it, share it with advertisers, or use it to decide creditworthiness or for lending.

## Data retention and deletion

Settings live on your device and are deleted when you uninstall Pace. Usage events are kept in PostHog for as long as they help us improve the product. To ask for the events tied to your install to be deleted, email us (below). Since the install ID is random, include roughly when you installed Pace and we'll do our best to find it.
